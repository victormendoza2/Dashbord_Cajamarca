Cargar capas

Sube los GeoJSON que preparaste en QGIS. Cada botón indica qué tipo de capa es. Puedes subir tantas capas de elementos expuestos como necesites y, en la tabla de abajo, elegir qué campo se usa como etiqueta de cada una.

Elementos expuestos: colegios, salud, vías, parcelas… en GeoJSON. Puedes subir los que quieras: el análisis usa todas las capas cargadas.

Compartir con un solo enlace

Cargas tus capas aquí y compartes un único enlace: quien lo abra las ve sin cargar nada. Si vuelves a compartir, el enlace es el mismo y se actualiza solo. Las capas se guardan comprimidas en un Gist secreto de tu cuenta de GitHub (no se agrega nada a tu repositorio).

Crear token
El token solo necesita el permiso «gist» y se guarda en este navegador. Cualquiera que tenga el enlace puede ver las capas (no aparece en búsquedas, pero tampoco tiene contraseña).
